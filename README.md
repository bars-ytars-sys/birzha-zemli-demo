# Биржа-Земли, демо интерфейса

Рабочий прототип площадки по продаже земли под базы отдыха, глэмпинги и эко-отели.
Открывается в браузере, без сборки и без сервера.

**Живое демо:** https://bars-ytars-sys.github.io/birzha-zemli-demo/

## Что показано

| Раздел | Что смотреть |
|---|---|
| Первый экран | поиск по региону, площади и запросу, сводка площадки за 30 дней |
| Каталог | фильтры, сортировка, счётчик просмотров и показов телефона на каждой карточке, динамика за 7 дней |
| Ранжирование | три правила выдачи с весами и пример расчёта позиции |
| Карточка объявления | галерея, характеристики, кнопка телефона, которая считает показ контакта |
| Кабинет продавца | статистика по объявлениям, динамика за полгода, сводка за месяц |
| Размещение участка | форма с проверкой полей, состоянием отправки и подтверждением |

Светлая и тёмная темы, мобильная вёрстка, работа без интернета.

## Состав

```
index.html               демо, ресурсы в img/ и font/
demo-single-file.html    то же самое одним файлом, картинки и шрифт внутри
presentation/            презентация по проекту
docs/                    как устроены счётчик и ранжирование
build.py                 собирает однофайловую версию из index.html
```

## Пересборка одного файла

```
python build.py
```

Скрипт подставляет содержимое `img/` и `font/` в `index.html` и сохраняет результат
в `demo-single-file.html`.
